# LangGraph Agentic Workflow

A local, API-triggered LangGraph agent system with a clear split between:

* **Core nodes** — reusable orchestration and execution primitives (agent, bash, initialize, advance, publish).
* **Project workflows** — ordered agent prompts, Bash scripts, inputs, and failure paths, defined per project.

See [docs/INITIAL.md](docs/INITIAL.md) for the full design, architecture, monorepo layout, and implementation phases.

## Status

This repository is a proof of concept. See the implementation phases and definition of done in [docs/INITIAL.md](docs/INITIAL.md).
